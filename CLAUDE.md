## Installing the apps
- The owner has an app on their iPhone that installs IPA files directly. When they ask for an IPA, just give the download link — no Sideloadly/AltStore instructions:
  https://github.com/lapinsauvage/chord-atlas/releases/latest/download/ChordAtlas.ipa
- If the IPA they want needs a new build (e.g. changes not yet in the latest release), run the `build.yml` workflow, then give the same link once the release is published.
